# Fed Labor Pivot Patch v2

Upload or merge these files into the root of `uptonke/yahoo-finance`.

This patch updates the standalone Fed labor-pivot data pipeline. It does **not** modify the existing `main.py` market-data workflow.

## What changed in v2

Added secondary labor-quality confirmation indicators:

```text
U6RATE
TEMPHELPS
AWHAETP
LNS13023621
```

Added inflation-gate indicators:

```text
PCEPI
PCEPILFE
CPIAUCSL
CPILFESL
```

Updated output logic:

- Core labor indicators still drive `numeric_regime_preliminary`.
- Secondary labor-quality indicators only raise/lower confidence; they cannot independently trigger `RED` or `PIVOT CONFIRMED`.
- Inflation indicators act as a constraint on Fed pivot space; they are not a standalone inflation monitor.
- Workflow now commits `data/fed_labor_pivot_monitor_history.jsonl` as well.

## Quick steps

1. Upload all files preserving folders.
2. Keep repository secret `FRED_API_KEY`.
3. Manually run `Fed Labor Pivot Data Fetch` once from GitHub Actions.
4. Keep cron-job.org triggering the workflow every Saturday 09:00 Asia/Taipei.
5. Point the ChatGPT weekly schedule to:

```text
https://raw.githubusercontent.com/uptonke/yahoo-finance/main/data/fed_labor_pivot_monitor.json
```
